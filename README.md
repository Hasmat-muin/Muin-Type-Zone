# বাংলা টাইপিং মাস্টার

বিজয় বায়ান্ন ও ইউনিকোড সাপোর্টসহ বাংলা টাইপিং শেখার ওয়েবসাইট।

- অক্ষর পরিচিতি (অ–ঁ), কিবোর্ড ও আঙুল গাইডসহ
- Bijoy Classic + Sutonny MJ (ANSI), Bijoy-to-Unicode এবং Unicode/Avro—তিন অনুশীলন মোড
- ANSI মোডে শেখা, বেলুন গেম ও টাইপিং পরীক্ষার যাচাইয়ের জন্য Bijoy লেখা Unicode-এ রূপান্তরিত হয়
- Classic + Sutonny মোডে কীবোর্ডে ইংরেজি কী-কোডের সঙ্গে ছোট বাংলা অক্ষরও দেখায়
- 🎈 বেলুন গেম
- ⏱ সময় ও সহজ/মধ্যম/কঠিন স্তর বেছে টাইপিং পরীক্ষা
- Unicode ফন্ট সিলেক্টর এবং ANSI ফন্ট সতর্কতা
- ANSI অনুশীলনের জন্য Sutonny MJ/TonnyBanglaMJ ডিভাইসে ইনস্টল থাকা দরকার; ANSI মোড শুধু টাইপের ঘরে প্রয়োগ হয়
- ANSI যাচাইয়ের জন্য `assets/bijoy-ansi-converter.js` ফাইলটি `index৩.html`-এর পাশের `assets` ফোল্ডারে রাখতে হবে
- Bijoy ANSI যাচাইয়ের কনভার্টারটি Naim Howlader-এর MIT-licensed `bijoy-unicode-converter`-এর mapping থেকে অভিযোজিত; attribution ও license: `assets/BIJOY-CONVERTER-NOTICE.txt`
- প্রথমে মুয়িনের ছবি ও পরিচিতিসহ স্বাগত পৃষ্ঠা দেখায়
